# CodeFlow

Independent software consultancy in Athens, Greece. We review code and architecture, give senior technical guidance, integrate agentic AI and build software for small and medium software companies.

## What we do

- **[Code & architecture review](https://codeflow.gr/code-review/)**: architecture, reliability and maintainability review, defined security checks against an OWASP ASVS-based checklist, and a prioritised written report with a walkthrough call.
- **[Senior technical guidance](https://codeflow.gr/services/)**: design reviews before implementation, pull request review on an agreed cadence, and architecture decision records for key choices.
- **[Agentic AI integration](https://codeflow.gr/agentic-ai/)**: agents on top of existing model APIs, retrieval pipelines, document extraction, and the evaluation and monitoring that keep the outputs in check.
- **[Build or complete software](https://codeflow.gr/services/)**: technical design, implementation with automated tests, CI/CD and a documented handover to your team.

Each service lists what it includes and what it does not on [codeflow.gr/services](https://codeflow.gr/services/).
